# Redmi AX6000: прошивка и подписанные пакеты

Прошивка для **Xiaomi Redmi Router AX6000, stock layout** на базе
[PadavanOnly ImmortalWrt 24.10 / Linux 6.6](https://github.com/padavanonly/immortalwrt-mt798x-6.6).
Настройки vendor-драйверов MediaTek сохранены. Прошивка, модули и SDK образуют
единый набор; ежедневные обновления используют SDK этой прошивки.
Установка прошивки выполняется владельцем вручную.

## Скачать и проверить

[Release с прошивкой, SDK и результатом сборки](https://github.com/valujin/ax6000-packages/releases/tag/firmware-redmi-ax6000-ec9ef10efc65-a3993ed37a41).
[Подписанный репозиторий пакетов и SDK](https://valujin.github.io/ax6000-packages/).
[Stock sysupgrade](https://valujin.github.io/ax6000-packages/firmware/redmi-ax6000-ec9ef10efc65-a3993ed37a41/immortalwrt-mediatek-filogic-xiaomi_redmi-router-ax6000-stock-squashfs-sysupgrade.bin)
и [SHA256SUMS](https://valujin.github.io/ax6000-packages/firmware/redmi-ax6000-ec9ef10efc65-a3993ed37a41/SHA256SUMS).

Сборка использует исходники `ec9ef10efc65da1e6d1de4e2c043c0e13d08eed8` и точный ABI:

```text
6.6.133~6ea4b96ad26e951cc0b4fa9296a521d3-r1
```

Фактическая полная сборка проверена: **1370 IPK, включая 1029 модулей ядра**.
Из её экспортированного SDK отдельно собраны и проверены **26 свежих пакетов**;
**1028 штатных модулей** сохранены побайтно из исходного набора. AmneziaWG
пересобран против того же ABI. SHA256 SDK:

```text
a3993ed37a4184931850f015201f3bd052c8e69f5d2ea184a02fc24d8d173549
```

Проверки инструментария прошли: 142 теста, включая реальные проверки
`usign`. Компиляция и проверки артефактов не подтверждают загрузку и работу
Wi-Fi на физическом роутере.

## Установка на роутер

Использовать только образ **stock layout**, сохранить настройки и данные
восстановления, проверить SHA256 и формат образа. Подробности:
[ручное обновление и проверка](docs/FLASH.md).
После ручной установки проверить Ethernet, Wi-Fi и ABI. Затем выполнить
**на самом роутере от root**:

```sh
opkg status kernel
# Version должен быть 6.6.133~6ea4b96ad26e951cc0b4fa9296a521d3-r1
ax6000-install-feed
```

Встроенная команда не принимает аргументов. Она проверяет точный ABI,
архитектуру, закреплённый ключ и подпись индекса, сохраняет резервные копии
настроек opkg, отключает другие активные feeds и выполняет `opkg update`.
Пакеты команда не устанавливает. Путь к резервной копии выводится как `Backup:`.

**Модули 6.6.133 несовместимы со старой прошивкой 6.6.95.** Не подключать новый
feed до установки соответствующей прошивки и не подменять зависимость `kernel`.

## Пакеты и профили

- Tailscale: стабильная официальная ARM64-сборка с проверкой SHA256.
- AmneziaWG 3.1: модуль, инструменты, netifd и LuCI-протокол.
- WireGuard, OpenVPN, IPsec/strongSwan, дополнительные PPP/L2TP-инструменты.
- PBR, mwan3/MultiWAN, banIP и соответствующие LuCI-приложения; русский LuCI.
- Все применимые модули target из полной сборки. Исключённые варианты
  зафиксированы в `build-selection.json`; альтернативные драйверы могут иметь
  взаимные конфликты установки.

Часть пакетов доступна для последующей установки и не включена в образ.
GeoIP-блокировка и маршрутизация по GeoIP — разные задачи;
см. [VPN и маршрутизация](docs/ROUTING.md).

`profiles/redmi-ax6000.json` — профиль ежедневных обновлений для проверенного
набора 6.6.133 с точными ABI, URL и SHA256 SDK. Штатные модули остаются из
исходной полной сборки; обновляются запрошенные пакеты и AmneziaWG.
`profiles/redmi-ax6000-legacy.json` сохраняет старый профиль 6.6.95 и выключен:
его исходный SDK больше недоступен на зеркале.
`profiles/redmi-ax6000-new.json` используется для отдельной полной сборки
прошивки, SDK и модулей.

## Автоматизация

Ежедневный мониторинг проверяет feeds `openwrt-24.10`, AmneziaWG и стабильный
Tailscale. Изменение источников или рецептов вызывает сборку; неизменившийся
набор пропускается. Ошибка сборки, проверки или подписи сохраняет последнюю
успешную публикацию. Обновление прошивки и ядра выполняется отдельно, вручную.

[CI, подпись и Pages](docs/CI.md) · [Ограниченная локальная сборка](docs/BUILD.md) ·
[Публикация готовой сборки](docs/PUBLISH.md).

см. [исследование](docs/KERNEL-6.18.md).
