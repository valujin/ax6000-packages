# AX6000 Firmware and Repository Implementation Plan

> **For agentic workers:** Use independent agents for source research, build implementation and verification, as explicitly requested by the user.

**Goal:** Produce a stock-layout firmware with matching downloadable modules and a signed package repository.
**Architecture:** Frozen vendor firmware baseline, generated SDK/ABI profile, separately monitored feeds and atomic Pages publication.
**Tech Stack:** OpenWrt Make, Python standard library, Bash, Docker, GitHub Actions, usign.
**Spec:** ../specs/2026-10-12-ax6000-packages-design.md

## Global Constraints

- Source ec9ef10efc65da1e6d1de4e2c043c0e13d08eed8; mediatek/filogic; aarch64_cortex-a53; stock AX6000.
- Preserve vendor drivers. No automatic flash or firmware-base upgrades.
- Local cap4CPUs and10GiB RAM, no swap, nice19/idle I/O.
- Kernel dependency must match generated firmware exactly; no force flags or vermagic rewrites.

## Review Focus

- Disabled legacy profile must not publish incompatible modules.
- New static Tailscale SHA refers to ARM64 archive, never Go source archive.
- Target-inapplicable kmods are reported; requested packages dropped by Kconfig fail.
- usign secret/public pairing and decompressed Packages signature verify.
- Failed publication never replaces previous deployed repository.
